在 Kotlin 中，`val (min, avg, max)` 是**解构声明（Destructuring Declaration）** 的语法，用于从一个**数据容器**（如数据类、数组、列表、Pair/Triple 等）中同时提取多个值，并分别赋值给多个变量。


### 核心作用
解构声明可以简化代码，避免逐个获取容器中的元素，让多值提取更直观。例如，从一个包含多个相关值的对象中一次性取出所有需要的属性。


### 常见使用场景

#### 1. 与数据类（data class）配合
数据类是最常用的解构场景，Kotlin 会为数据类自动生成 `componentN()` 函数（`component1()`、`component2()` 等），用于解构提取属性：
```kotlin
// 定义数据类（自动生成 component1、component2、component3 函数）
data class Statistics(val min: Int, val avg: Int, val max: Int)

fun main() {
    val stats = Statistics(10, 50, 90)
    
    // 解构声明：同时提取 min、avg、max
    val (min, avg, max) = stats
    
    println("最小值: $min")   // 输出：最小值: 10
    println("平均值: $avg")  // 输出：平均值: 50
    println("最大值: $max")  // 输出：最大值: 90
}
```


#### 2. 与数组/列表配合
数组和列表也支持解构，但需要注意索引对应关系（从 `component1()` 对应索引 0 开始）：
```kotlin
fun main() {
    val numbers = arrayOf(10, 50, 90)  // 数组
    
    // 解构数组：component1()=10, component2()=50, component3()=90
    val (a, b, c) = numbers
    println("$a, $b, $c")  // 输出：10, 50, 90

    val list = listOf("apple", "banana", "cherry")  // 列表
    val (x, y, z) = list
    println("$x, $y, $z")  // 输出：apple, banana, cherry
}
```


#### 3. 与 Pair/Triple 配合
Kotlin 标准库中的 `Pair`（二元组）和 `Triple`（三元组）专门用于存储多个值，非常适合解构：
```kotlin
fun main() {
    // Triple 存储三个值
    val triple = Triple(10, 50, 90)
    
    // 解构 Triple
    val (min, avg, max) = triple
    println("min=$min, avg=$avg, max=$max")  // 输出：min=10, avg=50, max=90

    // Pair 存储两个值
    val pair = Pair("name", "Alice")
    val (key, value) = pair
    println("$key: $value")  // 输出：name: Alice
}
```


### 原理：componentN() 函数
解构声明的本质是调用对象的 `componentN()` 函数（`N` 为正整数），例如：
```kotlin
val (min, avg, max) = stats
// 等价于：
val min = stats.component1()
val avg = stats.component2()
val max = stats.component3()
```

- 数据类会**自动生成**这些函数（按属性声明顺序）。
- 非数据类若要支持解构，需手动定义 `componentN()` 函数并标记为 `operator`：
  ```kotlin
  class Result(val a: Int, val b: Int) {
      // 手动定义 component 函数
      operator fun component1() = a
      operator fun component2() = b
  }

  fun main() {
      val result = Result(100, 200)
      val (x, y) = result  // 解构生效
      println(x + y)  // 输出：300
  }
  ```


### 注意事项
1. **变量数量必须匹配**：解构的变量数量不能超过容器可提供的 `componentN()` 数量，否则编译报错：
   ```kotlin
   val (a, b, c) = Pair(1, 2)  // 错误！Pair 只有 component1() 和 component2()
   ```

2. **下划线忽略不需要的变量**：若不需要某个值，可用 `_` 占位（避免声明无用变量）：
   ```kotlin
   val (_, avg, _) = stats  // 只关心平均值，忽略 min 和 max
   ```

3. **支持嵌套解构**：解构可以嵌套，例如从包含数据类的列表中解构：
   ```kotlin
   val list = listOf(Statistics(10, 50, 90), Statistics(20, 60, 100))
   val (_, (a, b, c)) = list.withIndex()  // 嵌套解构（获取第二个元素的属性）
   ```


### 总结
`val (min, avg, max)` 是 Kotlin 的**解构声明**语法，用于从数据容器中一次性提取多个值，简化多变量赋值代码。其底层依赖 `componentN()` 函数，数据类、数组、列表、Pair/Triple 等均原生支持，非数据类可通过手动定义 `componentN()` 函数扩展支持。
